# DOB-Hub Capabilities Matrix (`CAP-01`–`CAP-20`)

Status labels follow strict verification evidence rules:
- **`WORKS`**: Proven by executable unit/behavioral tests running real production code (`tests/*.test.ts`) without requiring unexecuted rules emulator, live browser, or staging runtime.
- **`PARTIAL`**: Core implementation works in tests, but a requested capability is intentionally scoped or incomplete.
- **`BROKEN`**: Known failing or non-functional in current state.
- **`UNVERIFIED`**: Relies on Firestore Security Rules execution (`tests/firestore-rules.test.ts` — `NOT RUN` here), live Cloud Run / Firebase staging data, or real-browser interaction (camera, responsive viewports, OAuth popup).
