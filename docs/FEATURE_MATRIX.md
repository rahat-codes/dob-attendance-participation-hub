# DOB-Hub Final Feature & Capability Matrix (F1–F20)

Strict evidence labeling convention used below:
- **`TEST real code`**: Verified by executable unit/behavior tests importing production modules in `tests/*.test.ts`.
- **`NOT RUN`**: Security rules emulator tests exist in `tests/firestore-rules.test.ts` (22 cases across 13 suites) but cannot run inside the sandbox without Java/Firestore emulator (`npm run emulators:exec` in CI).
- **`READ`**: Verified by reading exact production source files/rules without live emulator/browser execution.
- **`MANUAL`**: Requires interactive verification in a real browser / Firebase staging project (checklists in `docs/RULES_MANUAL_CHECK.md`, `docs/PHASE4_MANUAL_CHECK.md`, `docs/PHASE6_MANUAL_CHECK.md`).
