# Firebase Console Rules Simulator Manual Checklist

Use the **Firebase Console -> Firestore Database -> Rules -> Rules Playground** to manually verify every security boundary below before/after deploying rules updates. Run each case against existing or seeded test documents (`members/mem_test_1`, `sessions/sess_open_1`, `sessionTokens/sess_open_1`, `users/uid_member_1`, `notifications/notif_1`).

| # | Test Scenario | Auth / Provider Context | Operation & Path | Payload / Preconditions | Expected Result |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **1** | **Valid Self Check-In** | Authenticated active user (`uid_member_1`), Google OAuth | `create` `/checkIns/sess_open_1_mem_test_1` | `id: "sess_open_1_mem_test_1"`, `sessionId: "sess_open_1"`, `memberId: "mem_test_1"`, `authUid: "uid_member_1"`, `method: "camera_scan"`, `token`: current 8-char `sessionTokens/sess_open_1.token` (rotated <= 75s ago), `checkedInAt: request.time`, `status: "present"`, matching `monthKey`, **no** `notes`/`verifiedBy` | **ALLOW** |
| **2** | **Empty Token Check-In** | Authenticated active user (`uid_member_1`) | `create` `/checkIns/sess_open_1_mem_test_1` | Same as #1, except `token: ""` | **DENY** (`tokenValid` requires 8 uppercase alphanumeric chars) |
| **3** | **Expired Token Check-In** | Authenticated active user (`uid_member_1`) | `create` `/checkIns/sess_open_1_mem_test_1` | `sessionTokens/sess_open_1.rotatedAt` is > 75s old (for `token`) or > 30s old (for `prevToken`) | **DENY** (`tokenValid` grace window expired) |
| **4** | **Closed / Completed Session Check-In** | Authenticated active user (`uid_member_1`) | `create` `/checkIns/sess_closed_1_mem_test_1` | Target session has `checkInMode: "closed"` OR `status: "completed"` OR `status: "cancelled"` (even with valid token) | **DENY** (`sessionOpen` rejects closed/completed/cancelled sessions) |
| **5** | **Member Reading Another Member's Private PII** | Authenticated active member (`uid_member_1`, owns `mem_test_1`) | `get` `/memberPrivate/mem_other_2` | Target `members/mem_other_2.authUid != "uid_member_1"` and user is not in `admins` | **DENY** (only admin or matching `members/{id}.authUid` allowed) |
| **6** | **Non-Admin Deleting a Session** | Authenticated active member (`uid_member_1`, not in `admins`) | `delete` `/sessions/sess_open_1` | Any valid session ID | **DENY** (`isAdmin()` required) |
| **7** | **Admin Deleting a Session** | Authenticated delegated admin (`uid_admin_1` exists in `admins/`) or verified Super Admin | `delete` `/sessions/sess_open_1` | Target session exists | **ALLOW** |
| **8** | **Notification `userId` Mutation** | Authenticated user (`uid_member_1`, owns `notif_1`) | `update` `/notifications/notif_1` | Existing `resource.data.userId == "uid_member_1"`; update attempts `userId: "uid_other_2"`, `read: true` | **DENY** (`userId` is immutable and owner may only change `read` / `dismissed`) |
| **9** | **Super Admin Without Verified Email** | Authenticated with Super Admin email, `email_verified: false` (or non-`google.com` provider) and not in `admins/` | `write` `/admins/uid_target` or `delete` `/sessions/sess_open_1` | `request.auth.token.email_verified == false` | **DENY** (`isSuper()` requires `email_verified == true && sign_in_provider == 'google.com'`) |
| **10** | **Application Submit with Valid Links** | Authenticated pending user (`uid_pending_1`, matches `users/uid_pending_1`) | `update` `/users/uid_pending_1` | Keeps `status: "pending"` and `email == resource.data.email`; sets `applicantName`, `applicantHandle`, `applicantTrack: "Software & Systems"`, `githubUrl: "https://github.com/octocat"`, `linkedinUrl: "https://www.linkedin.com/in/octocat-builder"`, `portfolioUrl: "https://octocat.dev"`, `showLinksPublicly: true` | **ALLOW** (and rejects `http://` or `localhost` links) |
